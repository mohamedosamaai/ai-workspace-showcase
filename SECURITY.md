## 2. Reporting a Security Vulnerability

We take the security of Bagback AI Workspace and all public showcase packages extremely seriously. If you discover a potential vulnerability or data leak:

1. **Do NOT open a public GitHub Issue.**
2. Use **[GitHub Private Vulnerability Reporting](https://github.com/mohamedosamaai/ai-workspace-showcase/security/advisories/new)** to submit your disclosure securely.
3. Alternatively, email **`im@mohamedosama.me`** or **`security@bagbacktech.com`** with:
   - Detailed description of the vulnerability.
   - Proof of Concept (PoC) steps.
   - Potential impact evaluation.
